# DAT 5668 — Agentic AI: Autonomous Decision-Making

Fall 2026. Washington University in St. Louis, Olin Business School.

This repository is the **student** set. It has the Monday sessions, Wednesday practice, homework, quizzes, project checklist, and figures. It does not include instructor solutions or quiz keys.

## Start here

1. Read [Students/README.md](Students/README.md).
2. Read [Students/Two-Agent-Families.md](Students/Two-Agent-Families.md). The course teaches **LLM-based agents** and **RL-based agents** as two ways to run the same loop: observe, decide, act, feedback.
3. Open the week folder. On Monday, run the worked example and fill the cells marked **Fill this with me** in class. On Wednesday, complete the practice notebook with the class.

Figures are in [assets/](assets/). Open the notebooks from this repository so those pictures resolve.
